## Recommended execution order

All four plans touch only `assets/css/style.css` and are independent of each
other (no shared line ranges, no plan depends on another's output). Recommended
order is by leverage, highest first:

1. **001** — five one-line value swaps, zero risk, immediately visible on
   every tap of an icon button across the whole site.
2. **002** — the only plan that adds a new block rather than editing existing
   lines; do it after 001 so the reduced-motion overrides are written against
   the already-fixed press-feedback values (no functional dependency, just a
   cleaner diff).
3. **003** — isolated to the admin order-status tabs, no interaction with 001/002.
4. **004** — purely cosmetic easing-curve swap on backdrops, safest to do last
   since it's the lowest severity and easiest to eyeball-verify in isolation.

There is no hard dependency between any two plans — they can also be executed
in a single pass or in parallel by different agents, since each specifies
exact line numbers and stops on drift rather than guessing.

## After executing

Run `improve-animations reconcile` to re-check this directory against the
