Conexión con GitHub

Para publicar cambios en la web necesitas un Personal Access Token de GitHub con permiso repo (o Contents: Read and write si es un token fine-grained) sobre este repositorio. Se genera en GitHub → Settings → Developer settings → Personal access tokens. El token se guarda únicamente en este navegador (localStorage), nunca se envía a ningún sitio salvo a la API de GitHub.

Estos tres primeros datos son siempre los mismos para esta web (ya vienen rellenos) — el dueño y el nombre del repositorio son los que aparecen en la URL de GitHub github.com/hezuradar/hezuradar-web, no tu usuario personal. Lo único que tienes que rellenar tú es el token.
